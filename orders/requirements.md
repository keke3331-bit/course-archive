# 講座アーカイブサイト 要件定義書

## 概要
過去に開催した講座の動画と資料を、後からアクセスできる形でアーカイブするためのサイト。

## 目的
- 受講者が過去回をいつでも見返せる
- 新規受講者にも過去の講座を視聴してもらえる
- 講師（自分）の知見をストック化する

## 機能要件

### コア機能
1. **講座一覧表示** — トップページで全講座をカード形式で一覧表示
2. **YouTube動画再生** — 各講座詳細ページで限定公開YouTube動画を埋め込み再生
3. **資料ダウンロード** — 各講座のPDF/PPT等の手元資料をダウンロード可能
4. **講座メタ情報表示** — タイトル、開催日、概要、所要時間、タグ

### 運用要件
- 講座追加は `src/data/courses.js` の配列に1エントリ追加するだけで完結
- 資料ファイルは `src/assets/materials/` に配置するだけ
- データ駆動設計のため、HTMLの個別編集不要

## 非機能要件

- **静的サイト** — GitHub Pagesで公開可能
- **ローカル動作** — `file://` でも完全動作（fetch不使用、JS内に直接データ埋込）
- **レスポンシブ** — スマホ/タブレット/PC全対応
- **アクセシビリティ** — semantic HTML、適切な見出し階層
- **ノーバックエンド** — DBもAPIも不要

## 動画ホスティング方針

- YouTubeに「限定公開（Unlisted）」でアップロード
- URLを知っている人のみアクセス可能（検索結果に出ない）
- iframe埋め込みで本サイトから再生

## 資料配信方針

- PDFを `src/assets/materials/` に配置
- 直接ダウンロードリンクで配信
- ファイル名規則：`course-<id>-<slug>.pdf`

## サイト構成

- `index.html` — 講座一覧
- `course.html?id=<id>` — 講座詳細（動画+資料）

## デザイン方向性
- 学習アーカイブにふさわしい落ち着いた色調
- 白基調 + ネイビーアクセント + 控えめなコーラル
- 読みやすい本文フォント（システム標準）
- 余白多めの上品な構成

## 公開方法
ローカル確認後、GitHub Pagesで公開（`docs/` ブランチ運用）。
