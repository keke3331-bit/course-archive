# サイトマップ

```
/
├── index.html         講座一覧トップ
└── course.html?id=N   講座詳細ページ（クエリ駆動・1テンプレで全講座対応）
```

## ページ別役割

| ページ | URL | 役割 |
|---|---|---|
| トップ | `/` または `/index.html` | 講座カード一覧、タグ/年度フィルタ、検索 |
| 講座詳細 | `/course.html?id=1` | YouTube動画埋込、講座概要、資料ダウンロード |

## ナビゲーション

- ヘッダー：サイト名（→トップへ戻る）
- フッター：シンプルなコピーライト表記のみ

## データ駆動

ページ追加不要。`src/data/courses.js` の `COURSES` 配列に1エントリ追加で新規講座を公開できる。
